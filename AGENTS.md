# Publication scope

- Commit only reusable SPICE verification know-how, generic tools and tests, documentation, and synthetic examples created for this repository.
- Never commit board or project-specific information: CAD, schematics, layouts, BOMs, firmware, real circuit decks, device-specific acceptance values, measurements, simulation results, RAW/CSV data, logs, reports, screenshots, or delivery archives.
- Keep project artifacts in the owning project's private workspace. Generalize lessons without retaining project identifiers, component references, wiring, numerical design limits, personal paths, or private URLs.
- Examples and tests must use synthetic circuits and generic data. Replacing a project name alone does not make a real circuit suitable for publication.
- Do not commit credentials or manufacturer models whose redistribution rights are unconfirmed.
- Before committing, inspect the staged file list and content for this boundary. Ignore rules are only a safeguard; do not bypass them to add project artifacts.
